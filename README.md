## 📖 About

**MN-RakSAMP** is a cross-platform **SA:MP client** designed for the **Arsacia Game SA:MP server** to simplify login and improve the user experience.  
It lets you manage multiple accounts efficiently while **minimizing resource usage**.

## ✨ Features

- ✅ Multi-account management
- ✅ Background connection service for each account
- ✅ Automatic login
- ✅ Resource-efficient (low CPU & memory usage)
